# 🎬 Netflix Data Analysis

> **An end-to-end Exploratory Data Analysis (EDA) project on the Netflix Movies & TV Shows dataset using Python.** This project uncovers trends, patterns, and business insights through data cleaning, visualization, and statistical analysis.

---

## 📖 Overview

Netflix has become one of the world's leading streaming platforms, offering thousands of movies and TV shows across different countries and genres.

This project explores the Netflix dataset to answer important business questions through Exploratory Data Analysis (EDA).

### Key Questions

- 📺 What percentage of Netflix content consists of Movies vs TV Shows?
- 🌍 Which countries contribute the most content?
- 📅 How has Netflix's content library grown over the years?
- 🎭 Which genres are the most popular?
- ⭐ Which content ratings appear most frequently?
- ⏱ What is the typical duration of Movies and TV Shows?
- 👨‍💼 Which directors have the highest number of titles?
